## Коротко

«Просмотрщик LAS» — настольное приложение для интерпретаторов
ООО НПФ «АМК ГОРИЗОНТ»: просмотр, обработка и анализ LAS-файлов ГИС с

### Этап 5, часть 2а — скрипты Python агента (2026-10-09, `8ef38db`)
Подробно — `ARCHITECTURE.md`, «ИИ-агент», пункт о `run_python`. Главное:

- Инструмент `run_python`: модель пишет скрипт для расчётов, графиков,
  диаграмм и таблиц. Пользователь видит код в окне `ScriptApprovalDialog` и
  подтверждает запуск (по умолчанию — «Отклонить»; можно разрешить без
  вопроса до конца диалога).
- Скрипт выполняет отдельный процесс (`engine/lasviewer_engine/script_runner.py`)
  с таймаутом 60 с (5–300), без окна консоли, в папке
  `%LOCALAPPDATA%\AMK\LasViewer\scripts\<дата время> <название>`. Готовые
  переменные: `np`, `pd`, `plt`, `files`, `las`, `df`, `save_figure`,
  `save_table`. Сеть, запуск программ, `ctypes` и запись вне папки
  запрещены перехватчиком аудита — защита от ошибок, граница безопасности —
  подтверждение пользователя.
- Движок отвечает на `agent.run_script` в отдельном потоке (`rpc.Background`):
  пока скрипт работает, остальные запросы обслуживаются. «Стоп» —
  `agent.cancel_script`.
- В чате (`ScriptResultView`) — графики (щелчок открывает файл), ссылки на
  таблицы и папку, код и вывод. Модели возвращается `print` и трассировка.
- `engine/requirements.txt`: numpy 2.3.5, pandas 2.3.3, matplotlib 3.10.8 с
  закреплёнными зависимостями. `artifacts\python` пересобран
  (`Prepare-Python.ps1`, ≈220 МБ вместо 22 МБ; сборка заняла ≈15 мин —
  загрузка и распаковка тысяч файлов). Установщик вырастет соответственно.
- Проверено: тесты движка и `Checks` (отказ, неверный файл, запуск с
  графиком через настоящий движок); встроенный Python в режиме `-I` —
  скрипт по `51_АК.las` со статистикой, графиком (кириллица в подписях
  отображается) и CSV, сеть блокируется. Сборка WinUI — без ошибок и
  предупреждений (в отдельную папку: приложение и VS были открыты).
- **Не проверено в окне:** окно подтверждения и показ графиков в чате с
  настоящей моделью — проверить запуском приложения: открыть файлы скважины
  51 и попросить «Построй гистограммы и кросс-плот УЭС зондов».

### Совместный планшет и кривые других файлов (2026-10-09, 0.4.0)
Просьба коллег (приоритет): файлы разных методов (например, ЭМК и РК) рядом
на одном экране, общий трек для кривых обоих методов, перенос кривой из
другого файла. Решения пользователя: заливки между кривыми разных методов
не делать; логику шаблонов пока не трогать; при переносе кривой из другого
файла создаётся новый трек с кривыми соседнего трека и перенесённой кривой.
Подробно — `ARCHITECTURE.md`, «Кривые других файлов и совместный планшет».

- У кривой и заливки — ссылка на файл (`Source`); планшет рисует из
  `TabletSources`, каждая кривая по своим глубинам — без пересчёта.
- Совместный планшет (меню «Планшет → Совместный планшет…», дерево проекта):
  треки каждого файла + пустой общий трек, одна колонка глубины, сдвиг файла
  по глубине при показе, узел «▦» в дереве проекта.
- Кривая другого файла (из дерева или с шапки соседнего планшета) на трек
  одного файла → новый трек сравнения справа (`TemplateEditing.PlaceCurve`).
- Разные единицы глубины — отказ, разные скважины (`WELL`) — вопрос.
- Проект версии 2 (совместные планшеты, ссылки на файлы номерами); версия 1
  читается. В библиотеку шаблонов чужие кривые не попадают.
- Проверено: `Checks` (источники и сдвиг, значения только в пределах записи,
  трек сравнения, подписи файлов, формат проекта 2 и чтение 1); запуск
  отдельной сборки на скважине 51 с проектом, где есть совместный планшет
  ЭМК + РК со сдвигом и трек сравнения на планшете ЭМК: кривые на месте,
  имена файлов над треками, вид восстанавливается, проект версии 1
  открывается.
- **Не проверено руками:** перетаскивание мышью (между планшетами, из
  дерева), диалоги создания и сдвига, закрытие файла, входящего в

## Правила работы с этим проектом

Безопасность и данные:
- **Ключ polza.ai никогда не коммитить и не выводить.** В
  `server/LlmController.php` в репозитории — заглушка `'ВСТАВЬТЕ_КЛЮЧ_POLZA_AI'`.
- Данные заказчиков (LAS, планшеты, архивы скважин) в git не класть.
- В `C:\Users\Admin\Desktop\horizon.ru` ничего не коммитить — там правки пользователя.
- Без явной просьбы не делать `git push` и ничего не выкладывать на хостинг.
- Не запускать GORIZONT с изменением его настроек и справочников без нужды:
  он сам дописывает `Work\D_names.txt`.

Работа с пользователем:
- Пишет по-русски; отвечать по-русски, без лишнего.
- Не угадывать форматы данных и правила интерпретации — спрашивать.
- В Word-документах менять только то, о чём просили; не добавлять текст.
- Коммиты — сообщением на русском в стиле истории («Этап N, часть M: …»).
- Проекты (`.lvproj`) с ручным сохранением оставить (решение пользователя
  2026-10-12): сохранение настроек планшета, совместных планшетов и пометок
  для него важно. Предложение заменить их автосохранением отклонено.
- Шаблоны планшета (меню «Шаблон», библиотека `.lvtpl`) оставить — решение
  пользователя 2026-10-13.

Технические ловушки, на которых уже обжигались:
- **WinUI TreeView:** не пересобирать узлы внутри `ItemInvoked` — повреждение
  кучи и вылет без исключения. Откладывать через `DispatcherQueue`.
- **Поток агента** приходит не в потоке интерфейса: в `AgentPane` всё — через `Post`.
- **PHP `json_decode($x, true)`** превращает `{}` в `[]`; в описаниях
  инструментов не должно быть пустых объектов (тест в `test_agent_tools.py`).
- **DeepSeek через polza.ai** с `tool_choice: none` всё равно зовёт
  инструмент — на последнем шаге инструменты просто не отправляются.
- **Отладочная сборка занята**, если у пользователя запущено приложение или
  открыта Visual Studio: собирать в отдельную папку
  (`dotnet build … -p:OutDir=<временная папка>\`), скопировав туда `engine`
  и `python` при необходимости.
- **Скрипты PowerShell с кириллицей** сохранять в UTF-8 с BOM — Windows
  PowerShell 5.1 иначе читает их в ANSI.
- **Масштаб экрана пользователя 125%**: координаты для снимков экрана
  (`CopyFromScreen`) умножать на 1,25.
- **Не слать нажатия клавиш через SendKeys** при проверке окна — они попадают
  в окно Claude. Только сообщения окон / UI Automation с проверкой переднего плана.
