# База знаний агента

Карточки, из которых агент берёт терминологию и правила интерпретации.
Движок читает их при старте (`lasviewer_engine/knowledge_base.py`), модель находит
нужные инструментом `search_knowledge` и открывает `get_knowledge`.
Оглавление (номер, заголовок, одна строка «о чём») модель видит в описании
инструмента всегда.

## Карточка

Файл `<раздел>/<имя>.md`; номер карточки — путь без `.md` (`vikiz/kachestvo`).
В начале — шапка между строками `---`:

```text
---
title: Качество каротажного материала ВИКИЗ
source: Методичка ВИКИЗ (2000)
pages: 58–62
methods: ВИКИЗ
mnemonics: IK05, IK07, IK10, IK14, IK20
status: эталон
summary: Требования к записи, допуски калибровки и повторного замера, допустимый диапазон разности фаз.
---
```

- `status`: `эталон` — из методического руководства, которое компания
  считает эталоном; `практика` — подтверждённые наработки компании (кто и
  когда утвердил — в тексте); `черновик` — не подтверждено, модель обязана
  об этом сказать.
- `summary` — одна строка, по ней модель решает, открывать ли карточку.
- `priority` (необязательно) — главные карточки метода: 1, 2, 3… Если открыт
  файл этого метода, карточка с наименьшим номером прикладывается к каждому
  вопросу вместе со словарём и лучшей карточкой по вопросу.
- Страницы в тексте («(с. 62)», «(табл. 4.1, с. 32)») — для тех, кто ведёт и
  проверяет карточки. Модели текст уходит без них (`strip_references`):
  пользователю сноски в ответах не нужны.
- Текст — пересказ своими словами со ссылками на страницы, не копия
  источника. Числа — как в источнике; прочитанное с графика помечается
  «приблизительно, по рис. …».
- Всё, что не из источника (наблюдения по файлам компании, выводы
  разработчика), — отдельным разделом с пометкой.

## Источники

- **Методичка ВИКИЗ (2000)** — Технология исследования нефтегазовых скважин
  на основе ВИКИЗ. Методическое руководство / ред. М. И. Эпов, Ю. Н. Антонов.
  Новосибирск: НИЦ ОИГГМ СО РАН, 2000. 122 с. Номера страниц — по изданию
  (совпадают с номерами страниц PDF).
