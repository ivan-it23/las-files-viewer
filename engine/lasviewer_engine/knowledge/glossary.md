# Словарь терминов

Термины — как в методическом руководстве. В ответах использовать именно их.

| Термин | Обозначение | Смысл |
| --- | --- | --- |
| ВИКИЗ | — | Высокочастотное индукционное каротажное изопараметрическое зондирование |
| Разность фаз | Δφ, град | Измеряемая величина: разность фаз ЭДС в двух измерительных катушках трёхкатушечного зонда |
| Кажущееся удельное электрическое сопротивление | ρк, Ом·м | Δφ, пересчитанная по зависимости для однородной среды. Равно УЭС только в однородной среде |
| Удельное электрическое сопротивление пласта | ρп, Ом·м | УЭС неизменённой (незатронутой проникновением) части пласта; находится инверсией |
| Зона проникновения | ρзп, rзп | Прискважинная область, где фильтрат бурового раствора вытеснил пластовый флюид; rзп — её внешний радиус |
| Окаймляющая зона | ρоз, rоз | Узкий кольцевой слой на внешней границе зоны проникновения со скоплением вытесненной минерализованной пластовой воды; ρоз ниже ρзп и ρп |
| Вмещающие породы | ρвм | Перекрывающие и подстилающие пласт отложения |
| УЭС бурового раствора | ρс | Сопротивление промывочной жидкости; rс — радиус скважины |
| Кривая зондирования | — | Показания пяти зондов на одной глубине как функция длины зонда (в ρк или Δφ) |
| Диаграмма ВИКИЗ | — | Совокупность кривых зондирования по глубине; обычно все пять зондов на одном поле |
| Длина зонда | L | Расстояние между генераторной и дальней измерительной катушками |
| База зонда | ΔL/L | Относительное расстояние между измерительными катушками |
| Изопараметрический зонд | — | Зонд, у которого √f·L и ΔL/L одинаковы для всех зондов: в однородной среде все зонды показывают одно ρк |
| Радиальное зондирование | — | Глубинность растёт с длиной зонда и снижением частоты: короткие зонды видят прискважинную часть, длинные — пласт |
| Повышающее проникновение | ρзп > ρп | Фильтрат повышает УЭС прискважинной части (пресный фильтрат, солёная пластовая вода) |
| Понижающее проникновение | ρзп < ρп | Прискважинная часть проводит лучше пласта (газ, часть нефтяных залежей, солёный раствор) |
| Нейтральное проникновение | ρзп ≈ ρп | Зона проникновения по УЭС не отличается от пласта |
| Радиальный градиент УЭС | — | Различие ρк зондов разной длины в одном пласте — главный признак коллектора |
| Инверсия (подбор) | — | Подбор параметров модели (ρп, ρзп, rзп, ρоз…) по кривым зондирования |
| Инверсия кривой зондирования | — | Смена монотонной кривой на кривую с экстремумом (минимумом) — признак окаймляющей зоны |
| Критическое значение УЭС | — | Граничное значение ρп для типа залежи по статистике каротажа, испытаний и керна; своё для каждой залежи |
| Точка записи | — | Глубина, к которой привязано показание зонда; у ВИКИЗ — удалённая измерительная катушка И1 |
| Радиальная глубинность | Rg | Наибольший радиус зоны проникновения, при котором ρп определяется с погрешностью не более 10 % (20 %) |
| Нуль-сигнал, стандарт-сигнал | 0°, 25° | Калибровочные уровни Δφ в записи |
| Начальные фазовые сдвиги («нули воздуха») | — | Показания прибора в воздухе, которые компенсируются при калибровке |
| Эксцентриситет | δe | Смещение прибора с оси скважины к стенке |
| ПС, ГК, НКТ | — | Самопроизвольная поляризация, гамма-каротаж, нейтронный каротаж по тепловым нейтронам — комплекс к ВИКИЗ |

## Как говорить

- Показания зондов — **кажущееся сопротивление ρк**, не «УЭС пласта».
  УЭС пласта ρп — результат интерпретации, а не показание.
- «Коллектор водонасыщенный / нефтенасыщенный / газонасыщенный /
  нефтеводонасыщенный»; «уплотнённый (малопроницаемый) пласт»; «глинистый
  пласт».
- Проникновение — «повышающее», «понижающее», «нейтральное»; не
  «положительное» или «прямое».
- Характер насыщения по одному ВИКИЗ — **качественная оценка**: вывод
  «коллектор продуктивный» делает интерпретатор по комплексу и
  критическим значениям залежи (с. 63, 71).
