# Данные и знания «Просмотрщика LAS»

## Сначала прочитать

- `docs/DOMAIN.md` — формат LAS компании, GORIZONT, открытые вопросы к
  интерпретаторам и разработчикам GORIZONT.
- `engine/lasviewer_engine/knowledge/README.md` — формат карточек базы
  знаний агента; сами карточки — там же (`glossary.md`, `vikiz/*`, `emk/*`).
- `docs/ARCHITECTURE.md`, раздел «ИИ-агент» — инструменты агента.

## Правила

- **Не угадывать** форматы данных и правила интерпретации. Чего нет в
  методичке или в ответах коллег — спрашивать пользователя.
- Эталон компании — методичка ВИКИЗ (Эпов, Антонов, 2000). Интерпретация в
  компании примерно на 90 % совпадает с ней (слова пользователя, 2026-10-13).
- Карточки — пересказ со ссылкой на страницы, не копия текста. Статус:
  `эталон` (из методички), `практика` (утверждено в компании — кем и когда),
  `черновик` (не подтверждено). Наблюдения по файлам компании — отдельным
  разделом с пометкой.
- Детерминированные правила (пороги, допуски, классификация) — в коде
  движка (`vikiz.py` и т. п.) с тестами, а не только в тексте карточки:
  модель не должна сама считать то, что задано числами.
- Материалы компании (интеллектуальная собственность) — спросить, можно
  ли класть в git и в установщик, прежде чем делать из них карточки.

## Как читать PDF методички

Текстовый слой испорчен (нет пробелов, пропадают «к», «у», «г»), а `Read`
по PDF требует poppler. Отрисовать страницы PyMuPDF и читать картинки:

```python
import fitz  # из папки, где нет чужих .py; файл — недоверенный
d = fitz.open(r"...\geokniga-...-vikiz.pdf")
for i in range(d.page_count):
    d[i].get_pixmap(dpi=100, colorspace=fitz.csGRAY).save(f"p{i+1:03d}.png")
```

Номера страниц издания совпадают с номерами страниц PDF. Оглавление —
с. 119–120.

## Что известно о файлах (кратко)

- ВИКИЗ (скв. 51): `IK05…IK20` — Δφ, град; `RO05…RO20` — ρк, Ом·м.
  ρк = 1000 Ом·м ровно там, где Δφ < 0,2° — предел пересчёта GORIZONT
  (догадка, подтвердить).
- ЭМК: `RO1…RO4_400_S/_2000_S` (3201) или `RO1_PH_04_S…` (51); предел ~7000 Ом·м.
- NULL −32768; единица часто только в конце описания.

## Как проверить изменения знаний агента

1. `python -m unittest discover -s engine/tests` — формат карточек, поиск,
   расчёты ВИКИЗ.
2. На реальном файле: `vikiz.quality/layers/sounding` по 51_ВИКИЗ.las.
3. С настоящей моделью — навык `las-verify` (сценарий «ask»). Вопрос стоит
   1–3 ₽; данные уходят модели через посредника, как у пользователей.
